---
description: Project status — objectives, key-result health, active work and hygiene issues
argument-hint: [project id]
---

Report the status of project $ARGUMENTS (when empty, use FLORQUE_PROJECT, or ask after `fwg projects`).

Run `fwg recipe project_overview project_id=<id>` and `fwg recipe hygiene project_id=<id>`.
Summarise: each objective with its key results (outcome, health, last value against target),
active initiatives, and the hygiene findings (initiatives serving nothing, incomplete key results,
stale proposals) with the node ids to fix.
